# Glossário

| Termo | Significado |
| --- | --- |
| Catálogo | Conjunto de livros disponíveis para busca |
| Livro | Obra/edição identificada no catálogo |
| Biblioteca pessoal | Associação entre leitor e livros selecionados |
| Item de biblioteca | Livro vinculado a um usuário, com status e progresso próprios |
| Progresso | Página atual registrada; percentual só quando total é conhecido |
| Quero ler | Intenção de leitura; wantToRead na API de referência |
| Lendo | Leitura em andamento; reading na API |
| Concluído | Leitura marcada como finalizada; finished na API |
| Sessão | Contexto autenticado que autoriza recursos pessoais |
| RF / RNF / RN | Requisito funcional / não funcional / regra de negócio |
| UC / CT / ADR | Caso de uso / caso de teste / registro de decisão arquitetural |
| Baseline | Versão de referência dos artefatos, sujeita a controle de mudanças |
